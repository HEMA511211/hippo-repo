# 概念学习资料生成 Skill

## 目的

帮助用户系统性地学习一个新概念。不是简单地"解释一下"，而是生成一套**可直接保存、反复阅读、互相链接**的学习资料，让概念在知识网络中扎根。

## 适用场景（触发条件）

- 用户明确要求学习/搞懂某个概念
- 用户要求为某个概念生成学习资料
- 用户在对话中反复追问同一个概念的不同侧面（此时可主动建议生成完整资料）

## 输入信息

- **必需**：一个学习主题（概念名称），如"Agent"、"注意力机制"
- **可选**：学习者的背景（初学者/有基础）、期望的深度、特定的疑问点

本 Skill 面向**任意新概念**通用，不绑定某次特定的学习任务。

## 工作流程

1. **确认概念**：明确要学习的概念名称。若概念有歧义（如"上下文"），先确认用户指的是哪个领域。
2. **设定学习目标**：为该概念写出 3~5 条可检验的学习目标（学完后应该能做什么）。
3. **提出核心问题**：列出围绕该概念的 2~3 个核心问题，作为学习主线。
4. **梳理知识结构**：围绕该概念整理四方面内容：
   - 概念本身：定义、核心机制或组成、常见误区、一个生活化类比
   - 概念的上下文：它出现在什么场景、解决什么问题、前置知识是什么
   - 概念的应用：一个具体应用场景、它作为一种"技能/工具"时如何使用、上手路径
   - 概念的关系：它与其他已学概念（或同领域核心概念）的关系，以及容易与之混淆的概念辨析
3. **生成 4 个 HTML 文件**，输出到 `learning-materials/` 目录：
   - `<concept>.html` —— 概念详解页
   - `<concept>-context.html` —— 上下文页（场景、问题、前置知识）
   - `<concept>-application.html` —— 应用/技能页
   - `<concept>-relationship.html` —— 概念关系图页
4. **互相链接**：4 个页面底部必须有导航链接，可以跳转到其他 3 个页面。
5. **汇报**：告知用户生成了哪些文件、建议的阅读顺序。

## 输出规范

### HTML 格式要求

- **自包含**：所有 CSS 内联在 `<style>` 中，不依赖外部资源，双击即可离线打开
- **中文**：正文使用简体中文，术语首次出现时标注英文原文
- **浅色主题**：白底深色文字，适合阅读和打印
- **结构统一**：每个页面包含——标题与一句话摘要 → 正文分节 → "一句话记住"总结 → 页面导航
- **编码**：UTF-8，`<meta charset="utf-8">`

### 内容质量要求

- 定义必须准确，不确定的内容要明确标注"存疑"而不是编造
- 每个概念至少给出 1 个类比、1 个例子、1 个常见误区
- 每个概念页必须包含：学习目标、核心问题、结构化解释、应用案例、概念辨析（易混淆点）、自测问题（附答案提示）、参考来源
- 篇幅适中：单页正文 800~1500 字，宁可精炼不要注水
- 关系图页使用内联 SVG 或 Mermaid 绘制概念地图，节点为概念、边标注关系类型

### 资料来源要求

- 每个概念页末尾列出 2~4 条**可核查的参考来源**，优先级：官方文档 > 领域经典论文/技术博客 > 权威教程
- **严禁伪造链接**：不确定 URL 是否真实存在时，宁可给出"来源名称 + 作者/机构 + 建议搜索关键词"，也不要编造 URL
- 引用的关键论断（如上下文窗口特性、Agent 组成）应能在来源中找到对应内容
- 提醒学习者：AI 生成的解释需人工核查，参考来源是核查的起点

### 自检要求

生成完毕后，按以下清单自检，未通过的项目必须修正后才算完成：

1. [ ] 4 个文件均已生成，且页面底部导航链接互相可达
2. [ ] 每页包含：学习目标、核心问题、定义、核心机制、类比、应用案例、易混淆辨析、自测问题、参考来源
3. [ ] 所有 HTML 自包含（无外部 CSS/JS 依赖），UTF-8 编码，双击可离线打开
4. [ ] 参考来源链接真实可访问（或按"名称+关键词"格式给出）
5. [ ] 概念解释中未包含无法核实的具体数字/引用；不确定处已标注"存疑"

### 文件命名

- 全部小写，单词间用连字符 `-`
- 示例：学习"Agent"概念 → `agent.html`、`agent-context.html`、`agent-application.html`、`agent-relationship.html`

## 示例

用户："帮我搞懂什么是 LLM 上下文"
→ 生成 `learning-materials/llm-context.html` 等 4 个文件，阅读顺序建议：概念页 → 上下文页 → 应用页 → 关系页。

## 边界

- 不生成与概念无关的内容，不偏离学习目的
- 用户未指定输出目录时，默认写入仓库的 `learning-materials/`
- 生成后提示用户可以 commit 到仓库，形成个人知识库的积累
