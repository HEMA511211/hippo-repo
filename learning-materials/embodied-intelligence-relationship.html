概念关系具身智能 × Agent × 上下文 × Skill

一句话摘要：具身智能是 Agent 理念从"数字世界"向"物理世界"的延伸——身体取代/扩展了工具集，物理环境取代了软件环境；而大模型的上下文与 Skill 机制，正是让这套物理闭环"听得懂、做得对、越用越熟"的三块基石。

概念地图

三条关系主线

关系说明
具身智能 ← AgentAgent 的"感知—决策—行动"循环在数字世界运转（调用软件工具）；具身智能把同一循环搬进物理世界，工具变成了传感器与执行器。可以说：具身智能 = 住在身体里的 Agent。
大模型上下文 → 闭环质量具身智能体的"大脑"仍是大模型，它依然只能利用上下文里的信息：传感器读数、任务指令、已执行步骤都要进入"工作桌面"。物理任务步骤多、耗时长，上下文管理的好坏直接决定机器人会不会"忘记"自己正在干什么。
Skill → 经验复用机器人学会"叠毛巾"之后，最好把这套动作方法论沉淀为可复用的技能文档/策略包，而不是每次从零学起。Skill 机制正是这种"一次学会、处处调用"的知识沉淀方式——未来机器人的技能库，很可能就是具身版的 SKILL.md。

一个完整场景串起四个概念

指令"把客厅收拾一下"下达给家用机器人：上下文里装着系统提示、指令与已完成的子步骤；大模型基于桌面上的信息规划"先捡玩具→再擦桌子"；每一步的传感器反馈写回上下文；如果"擦桌子"的方法曾沉淀为Skill，直接加载即可，不必重新规划；而整个系统作为具身 Agent，用手（执行器）在物理世界里完成闭环。四个概念各司其职，缺一则系统退化为"会聊天的摆设"。

个人理解与判断

我认为具身智能最大的启发不在"机器人变聪明了"，而是它反过来提醒我们：智能天然是长在"身体与环境"里的，纯数字智能只是智能的一个特例。对照本仓库前三个概念：Agent 教会我们"会做"的框架，上下文提醒我们"看见什么决定想出什么"，Skill 说明"沉淀让能力复利"——具身智能把这三条全部放进物理世界接受检验，也因此成为检验这三条理念是否真正成立的终极考场。

一句话记住

🎯 具身智能把 Agent 的闭环搬进物理世界；上下文是它的工作桌面，Skill 是它的肌肉记忆。
