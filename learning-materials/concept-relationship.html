概念关系图Agent · LLM 上下文 · Skill

一句话摘要：LLM 上下文是底层资源（模型知道什么），Skill 是结构化的经验注入方式（把方法放进上下文），Agent 是运行时系统（利用上下文和技能自主完成任务）——三者构成"资源 → 方法 → 执行"的层级关系。

关系详解

关系说明
上下文 → AgentAgent 的每一步决策都基于上下文中的信息；上下文是 Agent 的"工作记忆"，决定了它知道什么、能引用什么。
Skill → 上下文Skill 文件本身平时"沉睡"在磁盘上，只在匹配任务时被加载进上下文——这是按需注入、节省窗口空间的巧妙设计。
Agent ↔ 工具Agent 通过调用工具（读写文件、执行命令）来行动；工具的返回结果又写回上下文，形成"行动 → 观察 → 再决策"循环。
Skill → AgentSkill 把人的经验固化为流程，Agent 加载后即按 SOP 执行——相当于给通用大脑装上专业操作手册。

一句话记住

🎯 上下文是"知道"，Skill 是"会做的方法"，Agent 是"真正去做"。三者叠加 = 一个既懂知识、又懂方法、还能动手的数字员工。
