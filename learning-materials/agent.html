概念详解Agent（智能体）

一句话摘要：Agent 是能够感知环境、自主做出决策并采取行动来完成目标的系统——在 AI 语境下，通常指"让大模型不只是回答问题，而是能使用工具、分步执行、自主完成任务的程序"。

定义

Agent（智能体）源自经济学与人工智能中的经典概念：一个处于某种环境中的实体，它能够感知（perceive）环境信息、根据内部策略决策（decide）、并执行行动（act）去影响环境，形成一个循环（常称为"感知—决策—行动"循环）。在当今大模型（LLM）领域，Agent 特指：以 LLM 为"大脑"，配上工具调用、记忆和任务规划能力，让它能多步骤地自主完成复杂任务的系统。

核心组成

  • 大脑（LLM）：负责理解任务、推理和决策下一步做什么。
  • 工具（Tools）：Agent 可以调用的外部能力，如读写文件、搜索网页、执行代码、调用 API。
  • 记忆（Memory）：记住之前的操作结果和用户偏好，供后续步骤使用。
  • 规划（Planning）：把大目标拆解成小步骤，逐步执行并根据反馈调整。

生活化类比

💭 类比：普通对话式 AI 像一位顾问——你问它答，但动手的还得是你；而 Agent 像一位全能助理——你只说"帮我把这份报告整理好发给团队"，它会自己查资料、写文档、发邮件，中途遇到问题还会自己想办法。

例子

📝 例子：你说"帮我调研三种博客框架并推荐一个"。一个编码类 Agent 会：① 搜索三个框架的官网与评价 → ② 读取对比数据 → ③ 在本地分别初始化小项目试跑 → ④ 综合给出推荐与理由。整个过程它自主分步执行，而不是一次性把所有话说完。

学习目标

  • 能用自己的话说出 Agent 与普通对话式 AI 的两点关键区别
  • 能列出 Agent 的四个核心组成并各举一例
  • 能针对一个具体任务，粗略设计出 Agent 的执行步骤

核心问题

  • 为什么"能调用工具"是 Agent 与聊天机器人的分水岭？
  • Agent 在多步执行中靠什么保持方向不跑偏？

常见误区

⚠️ 误区一：Agent ≠ 聊天机器人。关键区别在于是否有"行动能力"（工具调用）和"自主性"（多步规划）。
⚠️ 误区二：Agent 万能论。Agent 的可靠性取决于其大脑（模型）与工具的质量，复杂任务中仍可能出错，需要人工监督（human-in-the-loop）。

使用边界

适合交给 Agent 的是步骤明确、结果可验证的任务（如代码修改后跑测试）；高风险、不可逆或强主观判断的任务（如对外发布、重要决策）应保留人工确认环节。

自测问题

  1. Agent 的"感知—决策—行动"循环中，工具调用发生在哪一环？（提示：行动）
  2. 把普通对话式 AI 变成 Agent，最少要增加哪种能力？（提示：工具调用）
  3. 为什么说 Agent 需要"记忆"？（提示：多步骤之间传递中间结果）
